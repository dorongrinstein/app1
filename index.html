How to play

Select four terms with a shared connection and press Submit group. For example: PUSH, PULL, FETCH, CLONE are Git commands. There is exactly one intended grouping for each puzzle.

You can make up to four mistakes. “One away” means three selected terms belong to the same group. Repeating a guess won’t cost another mistake.

Daily progress is saved on this device. Practice games are separate. Enter submits a group; Escape clears your selection.
